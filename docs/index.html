Same hand, seven different answers

This is one real deal, shown to every character in turn. The cards do not change — only who is holding them.

Put your own model at the table

Any model that speaks the OpenAI API can take a seat — a hosted one, a local one, whatever you already have. Point a seat at it, and it plays with the character you gave it.

A good way to compare models. Give two of them the same seat, the same character and the same cards, and see which one actually plays poker.

Deal yourself in

Needs Python 3.11 or newer. Nothing else to set up first.

# grab it and install
git clone https://github.com/jiale-wangOwO/LLM-Poker-Arena.git
cd LLM-Poker-Arena
pip install -r requirements.txt

# watch a game straight away -- no key, no model, no setup
python main.py --demo

# take a seat yourself
python main.py --me

# the table in your browser
python -m pokerarena.web --port 8080
# now open http://127.0.0.1:8080

Adding a model takes one form: open Settings → Providers, paste a base URL, a model name and a key. Your key is saved on your own machine and is never sent back to the browser.

On Windows, if you use a system HTTP proxy, add 127.0.0.1 to NO_PROXY — otherwise local requests can get routed through the proxy and fail.
